Ensemble Radar

Pre-token protocols, ranked by what a token would be worth — priced by five signals, not one.

How the ranking works

Every protocol gets five scores from 0 to 100, each from the snapshot alone. Scale is log TVL. Momentum is the 7-day TVL change. Tenure is how long it has run with no token recorded. Breadth is how many chains it runs on. Peer is the multiple its own category's tokened protocols actually trade at. The ensemble blends them (scale 30, momentum 20, tenure 15, breadth 10, peer 25), and the implied value is TVL at the category peer multiple, tilted by the ensemble. When the five signals disagree, the row says so — agree, mixed or split — instead of hiding the argument.

Nothing here predicts a token launch. It prices what a token would be worth if the record stayed as it is. A protocol “records no token” when the snapshot carries no market cap, CoinGecko id or symbol for it.
